## 2. ON-PAGE SEO OPTIMIZATION

### 2.1 Meta Tags & Titles

**Homepage Meta Title:**
- Current: (To be optimized)
- Recommended: "Tamilaga Vettri Kazhagam (TVK) | Official Political Party Website | Tamil Nadu"
- Length: 60-65 characters
- Include: Brand name, party description, location

**Homepage Meta Description:**
- Current: (To be optimized)
- Recommended: "TVK - Tamilaga Vettri Kazhagam, Tamil Nadu's political party founded by Vijay. Discover TVK's vision, manifesto, welfare schemes, and join our movement for progressive Tamil Nadu."
- Length: 155-160 characters
- Include: Keywords, call-to-action, unique value proposition

**Content Pages Meta Tags Template:**
- Titles: 50-60 characters
- Descriptions: 150-160 characters
- Include target keyword in first 100 characters of title
- Use active voice, include benefit statement

### 2.2 Heading Structure (H1-H6)

**Best Practices:**
- Only ONE H1 per page (usually the main title)
- H1 should include primary keyword naturally
- Use H2-H6 for logical hierarchy
- Each section should have an H2 heading
- Include LSI (Latent Semantic Indexing) keywords

**Example H1:** "Join TVK: Progressive Political Party for Tamil Nadu's Future"

### 2.3 URL Structure Optimization

**Current Issues to Fix:**
- Avoid: Unclear, non-descriptive URLs
- Instead use: Descriptive, keyword-rich URLs

**Recommended URL Patterns:**
```
tvkvijay.com/about-tvk
tvkvijay.com/manifesto/welfare-schemes
tvkvijay.com/news/tvk-election-results
tvkvijay.com/join-tvk/membership
tvkvijay.com/leadership/vijay-president
tvkvijay.com/contact/office-locations
```

**URL Best Practices:**
- Keep URLs short (3-5 words max)
- Use hyphens for word separation
- Include primary keyword when relevant
- Avoid special characters, numbers
- Use lowercase letters
- Create descriptive, user-friendly URLs

### 2.4 Content Optimization

**Content Quality Guidelines:**
- Minimum 1,500 words for main pages
- 800-1,200 words for secondary pages
- 300-500 words for news articles
- Maintain keyword density: 1-2% for primary keyword

**Content Structure:**
1. Introduction (100-150 words)
2. Problem/Need identification (150-200 words)
3. Solution (TVK's approach) (400-600 words)
4. Key points/features (bullet points)
5. Call-to-action (50-100 words)
6. FAQ section (200-300 words)

**Keyword Placement:**
- Use primary keyword in first 100 words
- Include keyword in H1 and at least 2 subheadings
- Place keyword naturally in first paragraph
- Use variations and related terms throughout
- Include keyword in image alt text
- Use keyword in internal links

### 2.5 Internal Linking Strategy

**Link Distribution:**
- Homepage: Link to 5-7 important pages
- Main pages (About, Manifesto, etc.): Link to 3-5 related pages
- News pages: Link to relevant policy pages
- Use descriptive anchor text (not "click here")

**Recommended Internal Links:**
```
Home → About TVK, Manifesto, Latest News, Join TVK
About TVK → Leadership, Ideology, History, Contact
Manifesto → Welfare Schemes, Policy Details, FAQ
News → Related Articles, Relevant Policies, Archives
```

**Anchor Text Best Practices:**
- Use relevant keywords in anchor text
- Vary anchor text (avoid exact match every time)
- Make links contextual and relevant
- Avoid pointing too many links to homepage

### 2.6 Image Optimization

**Image Requirements:**
- Use high-quality images (minimum 1200x800px)
- File size: Optimize to <200KB without losing quality
- Format: WebP (best), JPG (backup), PNG (when needed)
- File names: Use descriptive names with keywords

**Alt Text Examples:**
```
Bad: "image1.jpg" alt="tvk"
Good: "tvk-vijay-chief-minister-oath-ceremony-nehru-stadium.jpg" 
      alt="Vijay takes oath as Tamil Nadu Chief Minister at Nehru Stadium"
```

**Image Best Practices:**
- Include captions with keywords
- Lazy load images for performance
- Use responsive images for different devices
- Compress images using tools like TinyPNG, ImageOptim
- Create image sitemaps

### 3.2 Mobile Optimization

**Critical Mobile Requirements:**
- Responsive design (works on all devices)
- Fast loading time (<3 seconds on 4G)
- Readable text without zooming
- Touch-friendly buttons (minimum 44x44px)
- Minimal pop-ups and interstitials
- No intrusive ads

**Mobile Optimization Checklist:**
- [ ] Test on multiple devices (iOS, Android)
- [ ] Use Google's Mobile-Friendly Test tool
- [ ] Optimize images for mobile
- [ ] Reduce redirects
- [ ] Enable browser caching
- [ ] Minify CSS and JavaScript

### 3.3 Page Speed Optimization

**Current Speed Assessment:**
- Test using: Google PageSpeed Insights, GTmetrix, Lighthouse
- Target metrics:
  - Largest Contentful Paint (LCP): <2.5 seconds
  - First Input Delay (FID): <100 milliseconds
  - Cumulative Layout Shift (CLS): <0.1

**Speed Optimization Strategies:**
1. **Image Optimization:**
   - Compress images (lossless compression)
   - Use WebP format
   - Implement lazy loading
   - Use responsive images

2. **Caching:**
   - Enable browser caching (304 Not Modified)
   - Use server-side caching
   - Implement CDN for static files
   - Cache time: 30 days for images, 7 days for CSS/JS

3. **Code Optimization:**
   - Minify CSS, JavaScript, HTML
   - Remove unused CSS (critical CSS inlining)
   - Defer non-critical JavaScript
   - Async loading for third-party scripts

4. **Server Optimization:**
   - Use GZIP compression
   - Enable HTTP/2
   - Upgrade hosting if needed
   - Reduce Time to First Byte (TTFB)

### 3.4 SSL & Security

**Implementation Checklist:**
- [ ] Install SSL certificate (HTTPS)
- [ ] Redirect HTTP to HTTPS
- [ ] Update all internal links to HTTPS
- [ ] Test SSL installation
- [ ] Monitor SSL validity
- [ ] Implement security headers

**Security Headers to Implement:**
```
Content-Security-Policy: default-src 'self'
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
X-XSS-Protection: 1; mode=block
Referrer-Policy: strict-origin-when-cross-origin
```

### 3.5 XML Sitemap & Robots.txt

**XML Sitemap Requirements:**
- Include all important pages
- Maximum 50,000 URLs per sitemap
- Update frequency: Weekly for news, Monthly for static pages
- Priority: News (0.9), Home (0.8), Policy pages (0.7)
- Submit to Google Search Console and Bing Webmaster Tools

**Sample Robots.txt:**
```
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /private/
Disallow: /test/
Sitemap: https://tvkvijay.com/sitemap.xml
Sitemap: https://tvkvijay.com/sitemap-news.xml
```
